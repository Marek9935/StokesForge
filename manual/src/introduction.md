# Introduction

StokesForge is a desktop application for analysing and plotting scientific
data, in the spirit of OriginLab: workbooks, graphs, fits and peak analysis,
with Python scripting through `pyst`.

Download it from the
[releases page](https://gitlab.com/askrzypczak/stokesforge/-/releases). This
manual matches the version shown in its title: open the manual published for
the version you installed. To report a mistake in the software or in this
manual, use the
[issue tracker](https://gitlab.com/askrzypczak/stokesforge/-/issues).
