## `pyst` scripts

- `pyst`: the writes of #67 reuse the commands, in a `Script` macro opened at the first mutation and aborted on an uncaught error/interruption. The engine has its own client identity; handles are revalidated after reservation. `set_values` replaces length and cells without changing the type or the provenance; `set_column` stays strict. `undo()` undoes the current group and makes a commit point. Graphic objects (`add_shape`, `remove_shape`, #76) also join this group, with a reread of the spec under reservation. Contract: `stokesforge-script/tests/mutations.rs`, `tests/graphs.rs`, `docs/python-and-scripting.md`.
- `pyst`: navigation (`root`, `children`, `info`) reads a single snapshot per call and keeps its epoch in all the returned handles. `column` keeps its numeric numpy view without copy; `values` copies the cells as `float`/`str`/`None`, without parsing the texts or confusing empty, empty string and NaN. Contract: `docs/python-and-scripting.md`, `stokesforge-script/tests/navigation.rs` (#66).
- `pyst` (#399): `set_graph` is a size door like the Graph Properties draft and `Action::SetFrameSize`: the size keys call the `compose` setters in the same `SetPlotSpec`, fix a legacy graph inside `prepare`, take their unit from the `unit=` keyword (never the Preferences) and refuse out-of-range values; `pyst.graph_size` reads `figure_layout` and never writes. `LengthUnit` lives in `stokesforge-plot`. #411: `set_graph` also switches the layer placement (`stokesforge_render_svg::set_layer_placement`, shared with Graph Properties) and sets a free layer through `compose::set_free_frame`.
- `pyst`: **frozen API V1 (#331), alpha (`pyst.__api_version__`, #356)**. The reference list (names, signatures, exceptions, option keys, keys of the returned dictionaries, enumerated values) is the "Frozen API V1" section of `docs/python-and-scripting.md`, in `pyst-api` blocks read by `stokesforge-script/tests/frozen_api.rs`. Any change to this list — additions included — is an explicit decision (issue or agreement of the user) made **in the same commit** as the code: update the list first, then bump `PYST_API_VERSION` and add the snapshot `stokesforge-script/tests/api-witnesses/vX.Y.txt` (`scripts/versions-aligned.sh --pyst-snapshot`) in the same commit (0.x: minor +1 for any change; rules in `docs/python-and-scripting.md` § API version). An option added to `plot`, `set_graph` or `set_column_meta` enters its constant (`PLOT_OPTIONS`, `SET_GRAPH_OPTIONS`, `COLUMN_META_FIELDS`, which feed the unknown-key message) and the `options` block; a parameter is named in English (`path`, `handle`, `values`); docstrings and error messages in English (docstrings since #376).
