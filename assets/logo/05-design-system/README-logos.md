# Logos

Logo retenu :

- `stokesforge-icon.svg` : icône d'application sur tuile `surface`.
- `stokesforge-mark.svg` : même dessin, sans tuile, fond clair.
- `stokesforge-mark-dark.svg` : même dessin, sans tuile, fond sombre (encre `#e6e9e7`).
- `stokesforge-lockup.svg`, `stokesforge-lockup-dark.svg` : logo horizontal avec le nom (viewBox 860 × 256, police système).

Explorations : `explore-axis-hammer.svg` (l'axe est le manche du marteau), `explore-excite-bande-lueur.svg` / `explore-excite-etoile.svg` / `explore-excite-bande.svg` / `explore-excite-lueur.svg` / `explore-excite-trait.svg` / `explore-excite-comete.svg` (le marteau frappe l'absorption, l'émission en naît ; dégradés vert → orange), `explore-excite-fall.svg` / `explore-excite-strike.svg` (arc de points), `explore-behind-axis.svg` / `explore-behind-axis-dent.svg` / `explore-behind-horn.svg` / `explore-behind-horn-dent.svg` (marteau posé sur l'émission, derrière l'absorption, nouvelle tête, déplacement de Stokes élargi), `explore-drop-still.svg` / `explore-drop-dent-still.svg` (marteau posé, devant le graphe), `explore-fall.svg` / `explore-fall-axis.svg` / `explore-fall-cartoon.svg` / `explore-fall-night.svg` (le marteau-axe tombe sur la bande d'émission), `explore-fallen.svg` / `explore-fallen-mark.svg` / `explore-fallen-mark-dark.svg` (le marteau tombé, appuyé contre la bande d'émission), `explore-hot-emission.svg` (émission incandescente), `explore-dark-tile.svg` (forge de nuit), `explore-favicon.svg` (favicon sans axe ni marteau).

Spectres : absorption (vert) et émission (orange) en miroir, un épaulement chacun, tourné vers l'extérieur ; l'écart des maxima est le déplacement de Stokes. Couleurs figées dans les fichiers (pas de `currentColor`). Enclume au trait, intérieur transparent.
